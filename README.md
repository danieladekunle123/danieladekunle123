# Hi, I'm Daniel 👋

I'm a Computer Science graduate from TU Dublin and a Packaged App Development Analyst at Accenture in Dublin, Ireland. I build full-stack applications and real-time platforms, and I enjoy turning ideas into polished products across frontend, backend and cloud.

I previously worked as a Software Engineer Intern at Amazon, where I built a dashboard-tagging feature in React, TypeScript and AWS Cloudscape, validated through unit, integration and end-to-end testing.

- **[IzRosh](https://izrosh.com)** - Full-Stack Developer & Project Lead (Aug 2026 – Present). Live music storefront for beats, drum kits, licensing, lesson bookings and digital downloads, built with React, Express, PostgreSQL, Prisma, Redis and Stripe
- **[Minglr](https://minglr.live)** - Co-Founder & Full-Stack Developer (Mar 2026 – Present). Live real-time social video platform for party-based matching, video rooms and messaging, built with React, TypeScript, Express, Socket.IO and mediasoup
- **[Dan & Dave Web Services](https://dandavewebservices.ie)** - Co-Founder & Full-Stack Developer (Jun 2026 – Present). Web development for trades and local service businesses, including client sites and a lead-management dashboard

- **[Cutroom](https://github.com/danieladekunle123/cutroom/releases/latest)** - Windows desktop app for cutting audio and video clips from YouTube, TikTok and Twitch links, exported as MP4 or MP3. Built with Electron, JavaScript, yt-dlp and FFmpeg

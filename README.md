# Hi, I'm Daniel 👋

I'm a Computer Science graduate from Dublin, Ireland, with experience building full-stack applications and real-time platforms.

I previously worked as a Software Engineer Intern at Amazon, where I developed customer-facing features using React, TypeScript and AWS technologies. I enjoy turning ideas into polished, production-ready products across frontend, backend and cloud infrastructure.

I'm currently building:

- [IzRosh](https://izrosh.com) - A full-stack music e-commerce platform for beats, bookings and digital products
- [Minglr](https://minglr.live) - A real-time social video platform with messaging, parties and video-based matching

I recently built:

- **WannaBet?** - A peer-to-peer esports wagering MVP with tournaments, real-time messaging, wallets and escrow functionality

I'm particularly interested in full-stack engineering, real-time systems, cloud technologies and building products people genuinely enjoy using.
